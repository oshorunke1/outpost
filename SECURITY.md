# Security

## Reporting a problem

Please use GitHub's private vulnerability reporting on this repository (the "Report a vulnerability" button under the Security tab). Do not open a public issue for a security problem.

This is a portfolio project with no live players, so there is no bounty, but every report gets a reply.

## What is in scope

The game framework's defenses against malicious clients are described, threat by threat, in [docs/threat-model.md](docs/threat-model.md), with the file and test behind each one. Backend, credential and agent threats join that document in later milestones.
